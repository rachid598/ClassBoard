# Guide de l'enseignant

ClassBoard s'utilise sans formation : tout se fait avec les deux barres d'outils et la
barre de favoris. Ce guide présente l'essentiel en 5 minutes.

## 1. Premier lancement : vos disciplines

Au tout premier démarrage, un assistant en trois étapes s'ouvre :

1. **Disciplines** : touchez la ou les disciplines que vous enseignez (plusieurs choix possibles).
2. **Apparence** : thème clair ou sombre, taille des boutons (« Grande » est conseillée sur un TBI).
3. **Favoris** : les outils proposés pour vos disciplines. Cochez, décochez, faites glisser pour réordonner.

Ces choix ne cloisonnent rien : un professeur de français peut toujours utiliser le compas.
Ils sont enregistrés dans votre profil Windows et **ne sont pas redemandés**.
Pour les modifier : menu **ClassBoard** (en haut à droite) › **Mon profil ClassBoard…**

## 2. L'écran

```
┌───────────────────────────────────────────────────────────────────────┐
│ Stylets  Couleur  Trait  Gomme │ Fonds │ Annuler Rétablir │ Pages ‹ › │ … Tableau Web Documents Bureau ClassBoard │
├───┬───────────────────────────────────────────────────────────────────┤
│ ★ │                                                                   │
│ ★ │                        zone d'écriture                            │
│ ★ │                                                                   │
│ ☆ │        ┌────────────────────────────────────────────┐             │
│   │        │ Stylo Gomme Surligneur Sélection … Laser … │             │
└───┴────────┴────────────────────────────────────────────┴─────────────┘
```

- **Barre du haut** : couleurs, épaisseurs, fonds de page, annuler, pages.
- **Barre flottante** (en bas) : les outils d'écriture. Elle se déplace en la faisant glisser par son bord.
- **Barre de favoris** (à gauche) : un toucher pose l'outil au centre de la page. L'étoile ☆ permet de modifier vos favoris.
- **Panneaux latéraux** : onglet de gauche = miniatures des pages ; onglet de droite = bibliothèque (images, applications, instruments).

## 3. Les gestes essentiels

| Je veux… | Je fais… |
|---|---|
| Écrire | **Stylo**, puis écrire au stylet ou au doigt |
| Effacer | **Gomme** (ou l'extrémité gomme du stylet) ; **Effacer** en haut vide la page |
| Surligner un texte | **Surligneur** |
| Déplacer / agrandir un objet | **Sélection**, puis toucher l'objet |
| Utiliser un widget (minuteur…) | **Interagir**, puis toucher le widget |
| Montrer quelque chose | **Laser** |
| Tracer un trait droit | **Ligne** (ou dessiner une forme : la reconnaissance la redresse) |
| Ajouter une page | **Pages** en haut, puis **‹ ›** pour naviguer |
| Changer de fond (Seyès, quadrillage) | **Fonds** en haut |
| Écrire en cursive scolaire | **Texte**, puis choisir la police **Marelle** ou **Écolier** |

## 4. Outils de classe

- **Minuteur** : choisir une durée (1 à 20 min), **Démarrer**. Un signal sonore retentit à la fin.
  Toucher les chiffres met en pause.
- **Tirage au sort** :
  - onglet **Élève** : coller la liste de la classe (un prénom par ligne), puis **Tirer un élève**.
    « Sans remise » évite de tirer deux fois le même élève ; ↺ remet tout le monde.
  - onglet **Groupes** : nombre de groupes ou d'élèves par groupe.
  - onglet **Dé** : 1 à 3 dés, de 6 à 20 faces.
  
  Les prénoms restent dans votre document ClassBoard, sur votre poste : rien n'est envoyé.

Autres outils (bibliothèque, onglet de droite) : règle, équerre, rapporteur, compas, repère,
masque, projecteur, loupe, chronomètre, calculatrice, graphique, horloge…

## 5. Annoter le bureau Windows et les autres logiciels

Bouton **Bureau** (en haut à droite) : ClassBoard devient transparent et vous écrivez par-dessus
n'importe quelle application (navigateur, manuel numérique, PDF…).
La petite palette permet de revenir à la **souris** pour utiliser l'application, puis de reprendre l'**annotation**.
Bouton **Tableau** pour revenir au tableau.

## 6. Documents

- ClassBoard **enregistre automatiquement** (toutes les 2 minutes) et à la fermeture.
- Bouton **Documents** : retrouver, renommer, dupliquer, supprimer vos documents.
- **Importer un PDF** : glisser le fichier sur le tableau, ou Documents › Importer. Chaque page devient une page annotable.
- **Exporter** en PDF (pour l'ENT ou la clé USB) : Documents › Exporter.
- Les documents d'**OpenBoard** (`.ubz`) s'ouvrent directement.

## 7. En cas de souci

- En mode bureau, plus rien ne réagit dans les autres logiciels : passez en mode **souris** dans la petite palette, ou revenez au **Tableau**.
- Revenir à la configuration d'origine : Mon profil ClassBoard › **Réinitialiser ma configuration**
  (vos documents ne sont pas touchés).
- Signaler un problème : https://github.com/rachid598/ClassBoard/issues (sans données d'élèves).
